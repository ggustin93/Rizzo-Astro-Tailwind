# 🚨 GUIDE D'URGENCE - Modification des coordonnées

## Christine, voici comment modifier vos coordonnées de contact :

### 1. Accéder à l'interface d'administration
1. **Aller sur** : https://crizzo-avocate.be/admin/
2. **Se connecter** avec vos identifiants

### 2. Modifier les coordonnées principales
1. **Cliquer sur "Configuration"** dans le menu de gauche
2. **Cliquer sur "Paramètres généraux"**
3. **Défiler jusqu'à "Informations de contact"**
4. Modifier les champs suivants selon vos besoins :
   - **Numéro de téléphone** : Format international avec `+` (ex: +32 479 80 50 02)
   - **Numéro WhatsApp** : Format sans espaces et sans `+` (ex: 32479805002)
   - **Email** : Votre adresse email professionnelle
   - **LinkedIn** : URL complète de votre profil LinkedIn
   - **Adresse du cabinet** : Adresse complète
   - **Lien Cal.com** : URL de votre page de réservation
5. **Cliquer sur "Enregistrer"** puis **"Publier"**

### 3. Vérifier les modifications
- Après publication, attendez 1-2 minutes
- Visitez votre site et vérifiez que les nouvelles coordonnées apparaissent :
  - Sur la page d'accueil (boutons d'appel)
  - Sur la page de contact
  - Dans le pied de page
  - Sur la page de signature email

### Important
- Les modifications sont appliquées automatiquement sur toutes les pages du site
- Les modifications peuvent prendre jusqu'à 5 minutes pour être visibles en ligne
- Si vous ne voyez pas les changements, essayez de vider le cache de votre navigateur (Ctrl+F5 ou Cmd+Shift+R)
